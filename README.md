## 読む順序

1. [提出一覧](docs/SUBMISSIONS.md)：全フェーズの提出ID、生成コード、採用/不採用/取消、証拠の粒度。
2. [予備戦加工](docs/PRELIM_PROCESSING.md)・[予備戦攻撃](docs/PRELIM_ATTACK.md)・[本戦加工](docs/FINAL_PROCESSING.md)・[本戦攻撃](docs/FINAL_ATTACK.md)：各処理の意味と最終版へのつながり。
3. [コード一覧](docs/CODE_INDEX.md)：収録した97ファイルそれぞれの役割。入口と依存コードを区別。
4. [再現手順](docs/REPRODUCE.md)：環境、必要な入力、主要演算の実行方法、完全再現できない範囲。
5. [来歴](provenance/code_manifest.json)・[提出台帳JSON](provenance/submissions.json)・[証拠照合](provenance/evidence.json)：元ファイル、版、ハッシュ、提出物との対応根拠。

## 構成

```text
experiments/             予備戦加工の採用系列と監査部品
attack_phase/src/        予備戦攻撃のアルゴリズム
attack_phase/scripts/    予備戦の予測生成・提出物構築
research/                本戦の生成・攻撃・比較・検証コード
research/claude/         本戦S3の構造層と候補ビルダー
research/runs/.../*.py   実験ディレクトリに保存されていた実行コードのみ
pwscup_public/           主要演算をデータ指定で試すための公開版入口
tests/                   人工データによる公開版入口の検証
docs/                    日本語の解説・提出対応表・再現手順
provenance/              個票を含まない来歴と提出情報
```

元コードの相対パスを維持しました。`research/runs/`にも実験データは含めていません。原コードは当時の固定パス・中間成果物を参照する研究用スクリプトです。現在の日時で当時のビルダーをそのまま動かせない箇所もあるため、[再現手順](docs/REPRODUCE.md)を先に確認してください。

## 含める範囲

提出済み系列に直接関係するコードとimport依存を抽出しました。依存ファイルには、不採用実験でも使われた関数が残っています。そのファイルにある全手法を提出・採用したという意味ではありません。採用経路は各フェーズの解説を正本とします。提出と関係のない約120実験の全記録、発表資料生成、外部AIの呼出しやブラウザ操作は収録対象外です。

配布データ・個票・予測CSV・提出ZIP・競技トークン・認証情報は含めていません。公式キットも転載せず、[公式リポジトリ](https://github.com/pwscup/pwscup2026-kit)を別途取得する構成です。データの入手・再配布条件は公式の案内に従ってください。

新しい公開版入口は主要演算を切り出したものです。当時の全生成・探索・送信をワンコマンドで再現するものではありません。データなし検証の範囲と、過去の実データによる検証結果は区別しています。
