# コード公開版の作成方針

2026-10-27、競技終了後の事後整理。

- 予備戦加工・予備戦攻撃・本戦加工・本戦攻撃の実提出につながるコードと、その依存コードを収録する。
- 提出ID、採用状態、生成手順、主要設定、コードの役割を日本語で説明する。未提出候補を実提出と扱わない。
- 元リポジトリの履歴は持ち込まず、新規リポジトリとして作成する。
- 配布データ、個票、予測CSV、提出ZIP、競技トークン、認証情報、ブラウザ記録、機械固有設定を含めない。
- 公式キットは転載せず、フェーズごとの公式リリースと参照先を明示する。
- 原コードの来歴・ハッシュ・依存関係と再現上の限界を残す。データなしの検証と当時の実データ再採点を区別する。
- 公開前に全ファイルの構文、内部参照、機密値混入、データ混入を検査し、新設する汎用実行入口は人工データで検証する。

進捗: 原コード97ファイル、4フェーズ解説、36件の提出台帳、公開用実行入口を作成済み。人工データ7テスト、過去コードhash5件、G22のCSV完全一致、最終MIA全値一致、最終AIAのCSV完全一致を確認。機密値・データ混入検査も通過。次はGitHubへの公開とリモート一致確認。
